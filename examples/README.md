# Examples

- `sec-facts-NVDA.json`, `sec-filings-NVDA.json`: real output of `scripts/sec.py`, fetched from SEC EDGAR on 2026-10-13.
  This is what an agent sees instead of the multi-megabyte companyfacts response. Figures are as reported in NVIDIA's
  filings; `derivedQ` marks a quarter computed from year-to-date or full-year values.
- `ledger.example.json`, `watch.example.json`: the file formats used by `scripts/ledger.py` and `scripts/desk.py`.
  The company "EXAMPLE" and every call in these two files are invented to show the format. They are not research.

Nothing in this folder is investment advice.
